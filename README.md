# ⚡ Smart Grid Network Design (CCNA Project)

## 📌 Project Overview
This project simulates a Smart Grid network infrastructure using Cisco Packet Tracer.

It includes:
- VLAN segmentation
- Router-on-a-Stick
- OSPF routing
- ACL Security
- Firewall filtering
- SSH secure remote access
- Port Security
- WAN connectivity between Substation and Control Center

## 🏗 Network Architecture
- Control Center
- Substation
- AMI Smart Meters
- WAN Routing

## 🔐 Security Features
- RTU VLAN protection using ACL
- WAN firewall ACL
- SSH instead of Telnet
- Switch Port Security

## 🛠 Technologies Used
- Cisco 2911 Routers
- Cisco 2960 Switches
- OSPF
- Extended ACL
- VLAN & Trunking
- SSH
